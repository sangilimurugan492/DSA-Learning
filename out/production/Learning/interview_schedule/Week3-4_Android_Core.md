## 🧠 Key Concepts to Memorize

### Android
- **Activity lifecycle:** onCreate → onStart → onResume → [running] → onPause → onStop → onDestroy
- **Fragment lifecycle:** onAttach → onCreate → onCreateView → onViewCreated → onStart → onResume → ... → onDestroyView → onDestroy → onDetach
- **MVVM:** View → ViewModel → Repository → API/DB
- **Room:** @Entity, @Dao, @Database, migrations, relations
- **Retrofit:** interface, converters, interceptors, OkHttp
- **WorkManager:** constraints, chaining, periodic, expedited
- **DataStore:** Preferences vs Proto, migration from SharedPreferences
- **Paging 3:** PagingSource → Pager → PagingData → Adapter

### Kotlin
- **Scope functions:** `let` (transform), `run` (compute), `with` (call), `apply` (configure), `also` (side-effect)
- **Sealed classes:** Restricted hierarchy, `when` is exhaustive
- **Data class:** auto-generates equals, hashCode, copy, toString
- **Extensions:** Add functions to existing classes without inheritance
- **Inline:** Reduces lambda overhead, `reified` preserves type info
