## 🧠 Key Concepts to Memorize

### Kotlin
- `val` = immutable reference, `var` = mutable
- Null safety: `?` (nullable), `?:` (elvis), `!!` (force), `?.` (safe call)
- `when` replaces `switch`
- String templates: `"Hello $name, age: ${age + 1}"`
- Smart cast: after `is` check, no explicit cast needed

### Java
- JVM = runtime, JDK = dev kit, JRE = runtime env
- Primitives: byte, short, int, long, float, double, char, boolean
- String is immutable, StringBuilder is mutable
- `==` compares references, `.equals()` compares values

### Git
- `git init` → `git add` → `git commit` → `git push`
- Branch: `git checkout -b feature/x`
- Merge: `git merge feature/x` (or PR)
- Rebase: rewrites history, use for clean log
- Conflict: `<<<<<<<`, `=======`, `>>>>>>>`
