# Kotlin Questions

This directory contains Kotlin interview questions and concepts organized by difficulty level: **Beginner**, **Intermediate**, and **Advanced**. Each topic file includes detailed explanations and code examples.

## Structure

| Level        | Folder           | Description                                                  |
|--------------|------------------|--------------------------------------------------------------|
| 🟢 Beginner  | `beginner/`      | Core syntax, variables, control flow, functions, null safety |
| 🟡 Intermediate | `intermediate/` | OOP, collections, extensions, lambdas, scope functions       |
| 🔴 Advanced  | `advanced/`      | Coroutines, flows, generics, delegates, DSLs                 |
