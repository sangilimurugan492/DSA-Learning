# Java Scenario-Based Questions

Real-world Java development scenarios that test practical problem-solving. Each scenario presents a problem and walks through the solution with code.

## Topics

1. [OOP Scenarios](OOPScenarios.md) — Design problems using inheritance, polymorphism, composition
2. [Android Java Scenarios](AndroidJavaScenarios.md) — Android development with Java
3. [Concurrency Scenarios](ConcurrencyScenarios.md) — Threading, synchronization, race conditions
4. [Collection Scenarios](CollectionScenarios.md) — Collection-related real-world problems
5. [Debugging Scenarios](DebuggingScenarios.md) — Memory leaks, crashes, performance

## How to Use
- Read the scenario description
- Try to solve it yourself first
- Compare with the provided solution
- Review the explanation and trade-offs
