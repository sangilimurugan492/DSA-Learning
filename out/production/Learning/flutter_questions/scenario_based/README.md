# Scenario-Based Questions

Real-world Flutter problems with practical solutions. Each scenario presents a problem, shows the ❌ bad approach, and explains the ✅ good approach with key takeaways.

## Topics

| File | Scenarios |
|------|-----------|
| [State Management](StateManagementScenarios.md) | Global state, cart, auth flow, form state, theme switching |
| [Performance](PerformanceScenarios.md) | Jank, rebuilds, list scrolling, image memory, heavy computation |
| [UI/UX](UIScenarios.md) | Complex layouts, responsive design, custom animations, forms |
| [Navigation](NavigationScenarios.md) | Deep links, nested nav, auth flow, tab state, back handling |
| [Debugging](DebuggingScenarios.md) | Memory leaks, setState errors, overflow, blank screen, crashes |

## How to Use
- Each scenario is a real interview question
- Try to solve it yourself first
- Then compare with the solution
- Focus on understanding the "why" behind each fix
