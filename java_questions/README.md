# Java Interview Questions

A comprehensive collection of Java interview questions organized by difficulty level. Covers core Java, OOP, Android-specific Java, and real-world scenarios.

## Structure

### Beginner
- [Basics](beginner/Basics.md) — JVM, JDK, JRE, compilation, data types
- [VariablesAndDataTypes](beginner/VariablesAndDataTypes.md) — Primitives, wrappers, type casting
- [ControlFlow](beginner/ControlFlow.md) — if/else, switch, loops, break/continue
- [Arrays](beginner/Arrays.md) — Declaration, iteration, multi-dimensional arrays
- [Strings](beginner/Strings.md) — String pool, immutability, StringBuilder
- [OOPBasics](beginner/OOPBasics.md) — Classes, objects, constructors, `this`/`super`

### Intermediate
- [OOP Concepts](intermediate/OOPConcepts.md) — Inheritance, polymorphism, encapsulation, abstraction
- [Collections](intermediate/Collections.md) — List, Set, Map, Queue, Iterator
- [Generics](intermediate/Generics.md) — Type parameters, wildcards, type erasure
- [ExceptionHandling](intermediate/ExceptionHandling.md) — Checked/unchecked, try-with-resources, custom exceptions
- [Concurrency](intermediate/Concurrency.md) — Threads, Runnable, synchronized, volatile
- [LambdaAndStreams](intermediate/LambdaAndStreams.md) — Functional interfaces, Stream API, collectors

### Advanced
- [JVM Internals](advanced/JVMInternals.md) — Memory areas, classloader, bytecode
- [GarbageCollection](advanced/GarbageCollection.md) — GC algorithms, memory leaks, tuning
- [ConcurrencyAdvanced](advanced/ConcurrencyAdvanced.md) — ExecutorService, CompletableFuture, locks, atomic
- [DesignPatterns](advanced/DesignPatterns.md) — Singleton, Builder, Factory, Observer, Strategy
- [ReflectionAndAnnotations](advanced/ReflectionAndAnnotations.md) — Class reflection, custom annotations
- [AndroidWithJava](advanced/AndroidWithJava.md) — Android-specific Java patterns, migration to Kotlin

### Scenario-Based
- [README](scenario_based/README.md) — Index of all scenario-based questions
- [OOP Scenarios](scenario_based/OOPScenarios.md) — Real-world OOP design problems
- [Android Java Scenarios](scenario_based/AndroidJavaScenarios.md) — Android development with Java
- [Concurrency Scenarios](scenario_based/ConcurrencyScenarios.md) — Threading and synchronization problems
- [Collection Scenarios](scenario_based/CollectionScenarios.md) — Collection-related real-world problems
- [Debugging Scenarios](scenario_based/DebuggingScenarios.md) — Memory leaks, crashes, performance

## How to Use
- Start with **Beginner** if you're new to Java
- Move to **Intermediate** for core OOP and Collections
- **Advanced** for JVM internals and concurrency
- **Scenario-Based** for real-world problem-solving practice
