## How to use a daily sheet
1. Open the week's file on Monday; tick each box as you finish — tick **Log** only when the 3-line summary is written.
2. Mark the summary 🔵 confident / 🟡 shaky / ❓ unknown — ❓ items are what Saturday revision pulls.
3. Never skip Sunday: quiz /10 goes in [Progress_Tracker](../Progress_Tracker.md); score < 7 → that week repeats on Saturday.
4. DSA runs in parallel from [DSA/PatternWise_Prep](../../DSA/PatternWise_Prep/MASTER_PLAN_24W.md) on the same calendar — 30–45 min on Mon/Wed/Fri.
