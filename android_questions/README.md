# Android Questions

## Structure

| Level        | Folder           | Description                                                  |
|--------------|------------------|--------------------------------------------------------------|
| 🟢 Beginner  | `beginner/`      | Core components, lifecycle, UI basics, intents, permissions  |
| 🟡 Intermediate | `intermediate/` | Architecture, navigation, data binding, WorkManager, testing |
| 🔴 Advanced  | `advanced/`      | Performance, DI, security, custom views, CI/CD               |
