# 🧪 Sunday Mock Test Log

> **Format:** Every Sunday — 2 hrs timed test (4–5 problems) + 1 hr review.
> **Mix:** 60% current week's patterns + 40% older patterns (spaced repetition).
> **Rule:** No hints for the first 30 minutes. Log every hint you reveal.

---

## 📋 How to Run Each Mock Test

1. Pick 4–5 problems from the week's file (or mix from previous weeks).
2. Set a 2-hour timer. Attempt without hints for the first 30 min.
3. After 30 min, hints are allowed — but mark those problems as 💡.
4. Score: 🧠 = 2 pts (no hints), 💡 = 1 pt (with hints), 📖 = 0 pts (read solution).
5. Spend the last hour: review mistakes, re-solve failed problems, update [Progress_Tracker.md](Progress_Tracker.md).
