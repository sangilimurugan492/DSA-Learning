## 🧠 Key Concepts to Memorize

### STAR Method (Behavioral)
- **S**ituation: Set the context
- **T**ask: What was your responsibility
- **A**ction: What YOU did (not "we")
- **R**esult: Quantifiable outcome

### Common Behavioral Questions
| Question | Key Points |
|----------|-----------|
| Tell me about yourself | Past → Present → Future, 2 min max |
| Why this company? | Specific reasons, not generic |
| Biggest challenge? | STAR, focus on YOUR action |
| Conflict with teammate? | Show empathy, data-driven resolution |
| Failure? | Take ownership, what you learned |
| Leadership? | Initiative, mentoring, driving results |

### Java Key Concepts
- **JVM Memory:** Heap (Young/Old gen), Stack, Metaspace, PC Register
- **GC:** Minor GC (Young gen), Major GC (Old gen), Full GC (entire heap)
- **Concurrency:** `synchronized` (intrinsic lock), `volatile` (visibility), `Atomic*` (CAS)
- **Collections:** ArrayList (dynamic array), LinkedList (doubly linked), HashMap (array + linked list + tree)
- **Generics:** Type erasure at compile time, `<? extends T>` (covariant), `<? super T>` (contravariant)
