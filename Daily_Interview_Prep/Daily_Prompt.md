## How to Use

1. **Copy** the text between the COPY markers above.
2. **Paste** it into your AI assistant (ChatGPT, Claude, Gemini, etc.).
3. **Replace** `[DAY]` with your day number (e.g., Day 1, Day 2...).
4. **Replace** `[DATE]` with today's date (e.g., Aug 7, 2026).
5. **Send** and follow along with the coach.

### Rotation Guide

| Day | DSA Problem | System Design Question |
|-----|-------------|----------------------|
| 1 | Kth Largest Element (Heap) | URL Shortener |
| 2 | Top K Frequent Elements (Heap) | Twitter / Social Feed |
| 3 | Merge K Sorted Lists (Heap) | Chat System (WhatsApp) |
| 4 | Find Median from Data Stream (Heap) | Rate Limiter |
| 5 | Two Sum - Sorted Array (Two Pointer) | Google Drive |
| 6 | Container With Most Water (Two Pointer) | Notification System |
| 7 | Longest Substring Without Repeating (Sliding Window) | Ticket Booking (BookMyShow) |

> After Day 7, loop back to Day 1 or pick new problems from the `DSA/` folder.

### Customizing the Prompt

- **Swap DSA problem**: Replace the DSA file paths with any problem from `DSA/` folder.
- **Swap system design**: Replace the case study section number (e.g., "Section 3" for Chat System).
- **Focus area**: Add a line like "Today I want to focus extra on Kotlin Null Safety" to get deeper coverage.
- **Time-box**: Add "Keep each topic to 15 minutes max" if you're short on time.
